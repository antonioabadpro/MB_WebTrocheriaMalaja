Repositorio del proyecto de la Actividad Académica Dirigida (AAD) de la asignatura **Motores de Búsqueda (MB)**.
El proyecto **Trochería VS Malajá** es una página web estática desarrollada con el objetivo principal de experimentar y aplicar técnicas de **SEO (Search Engine Optimization)** para lograr su indexación en los principales motores de búsqueda.

[![Netlify Status](https://img.shields.io/badge/Visitar_Sitio-trocheriamalaja.netlify.app-00AD9F?style=for-the-badge&logo=netlify)](https://trocheriamalaja.netlify.app/)
> **Nota:** Haz clic en el botón de arriba para visualizar el sitio web.

---

## 🎯 Objetivo del Proyecto

El propósito es posicionar una web que define y compara dos términos coloquiales onubenses: **"Trochería"** y **"Malajá"**.

La web está optimizada para:
- Indexación rápida por parte de crawlers (Googlebot).
- Estructura semántica correcta.
- Carga rápida y diseño responsive.

---

## 🛠️ Tecnologías Utilizadas

### Frontend

El proyecto ha sido construido utilizando estándares web nativos para maximizar el rendimiento y la compatibilidad:

- **HTML5:** Uso intensivo de etiquetas semánticas (`<header>`, `<article>`, `<section>`, `<footer>`) para mejorar la legibilidad de cara a los motores de búsqueda.
- **CSS3:** Hoja de estilos personalizada (`estilo.css`) para el diseño visual, sin uso de frameworks pesados para mejorar los tiempos de carga (Core Web Vitals).
- **JavaScript (Vanilla):** Lógica del cliente (`funciones.js`) para elementos interactivos como el "Test Rápido", sin dependencias externas.

### 🔍 Herramientas de SEO Incluidas
El repositorio incluye archivos específicos para la gestión de robots e indexación:
- **`sitemap.xml`:** Mapa del sitio para guiar a los rastreadores sobre la estructura de las URLs.
- **`robots.txt`:** Archivo de directivas para permitir o bloquear el acceso de los bots a ciertas partes de la web.
- **`google[id].html`:** Archivo de verificación de propiedad para **Google Search Console**.

A continuación se detalla la organización de los archivos principales:

```text
├── robots.txt         # Directivas para crawlers

```
